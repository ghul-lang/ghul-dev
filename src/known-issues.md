# known issues

Known problems with the compiler and with the [Visual Studio Code language extension](https://marketplace.visualstudio.com/items?itemName=degory.ghul) are tracked as issues in the [ghūl compiler repository](https://github.com/ghul-lang/ghul/issues). If you find a problem that isn't recorded there, please raise an issue. If an existing issue is blocking you, add a comment to it, or raise a PR with a fix.

Every open bug has a priority from `P0` to `P3`, set by how the bug affects you rather than by how hard it is to fix. [How bugs are prioritized](https://github.com/ghul-lang/ghul/blob/main/CONTRIBUTING.md#how-bugs-are-prioritised) defines each one.

- [open issues](https://github.com/ghul-lang/ghul/issues)
- [open issues in the language extension](https://github.com/ghul-lang/ghul/issues?q=is%3Aissue+is%3Aopen+label%3Aghul-vsce)
